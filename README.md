# SkyTube

SkyTube is a modern alternative YouTube-style frontend built with React and Vite.

## Features
- Clean, dark, creator-focused interface
- Responsive video grid and category filters
- Featured content banner and creator highlights
- Interactive watch view with suggested videos
- Search and category-based filtering

## Run locally
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build
```bash
npm run build
```
